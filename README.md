# Yuno

一个自己写的第三方 Apple Music 安卓客户端。界面是 Compose 一帧一帧画出来的，歌词页做到了逐字跟着唱的卡拉 OK 效果。

## 这是什么

Yuno 绑定你自己的 Apple 账号，从 Apple Music 拿订阅、资料库、推荐和歌词数据，然后用一套完全自绘的界面把它放出来。

起因其实很小：受够了歌词只能整行高亮，想做那种字一个一个跟着唱亮起来的效果。做完之后发现停不下来，就顺手把播放器、底栏、设置页、歌词背景这些也重做了一遍。做到 2.0.0 的时候已经积累了不少坏味道，于是干脆推倒，把业务核心搬到 Rust，界面按功能拆成十几个模块。

## 和官方 Apple Music 的差别

官方客户端的歌词是它自己的排版和节奏，很多人喜欢，但有些细节没法调。Yuno 从一开始就是照着自己想要的手感做的，所以差别其实挺明显：

**歌词是逐字扫光，不是逐字跳白。** 官方的高亮是字唱到就亮，Yuno 是一道光从字的左边扫到右边，边界的羽化是柔和渐变的，不是一条硬线。正在唱的那个字会同时被拉伸一点点，唱完就锁住，只要这一句还在播就不缩回去；换句之后随滚动缩回原尺寸。

**歌词的每一层亮度是分开调的。** 当前句、唱过的句子、还没唱的句子，三档亮度各自独立。唱完的句子会暗下去，跟没播的一个亮度，不会一直亮着抢戏。

**排版混了 Material 3。** 官方是纯 Apple 的排版密度和气质，Yuno 在卡片、圆角、留白、控件上用的是 M3 的做法，所以看起来是另一种调子。设置面板、搜索页、登录页这些都是标准 M3 组件。

**架构是模块化的。** 官方客户端是一整个巨型工程，Yuno 拆成了十几个 Gradle 模块加一个 Rust 工作区，依赖方向由构建图强制单向，反向依赖编译不过。歌词时间轴、TTML 解析、清单重写这些纯计算逻辑放在 Rust 侧，有五十多个单元测试盯着。

**数据只在你自己机器上。** 账号凭据存在本机，日志里不含令牌，也没有任何上报。

## 特色

**逐字卡拉 OK 歌词。** 这是整个项目花时间最多的地方。每个汉字有独立的时间域，源数据只给词级时间戳的时候会在词内均分成字级，所以"AB"这种词组也是 A 先亮、B 后亮，不会两个字一起闪。同一句话折行的时候，跨在两行中间的那个字单独处理，不会被裁掉也不会整块闪现。字与字之间的间距、放大比例、边界羽化宽度都是可以调的参数。

**等待球。** 前奏和长间奏的时候，标题栏和歌词之间那片空白里会出现三个点，从左到右挨个亮起来。间奏短于 4.75 秒就不显示，不值得为那么短的停顿插个东西。

**完整曲目播放。** 不是三十秒试听。全曲链路打通了，万一某首解不了会自动降级到试听，不会直接卡住。

**三套歌词源。** Apple 私有 TTML、LRCLIB、网易云，可以在设置里切。TTML 那套能拿到逐字时间戳、背景人声、翻译和音译，LRCLIB 和网易云做兜底。歌词有缓存，切源的时候会做时间轴健康检查，坏数据直接丢掉换下一家。

**液态玻璃底栏。** 主页和资料库两个胶囊合成一段，搜索是个独立的圆钮。用 Haze 做的，比苹果原版更糊一点、通透度更低，但折射的光学效果保留着。

**音质分档。** 无损和高解析度无损两档，另外有个杜比全景声的独立开关。清单里的流会按你选的档位排序。

**歌词页背景跟着专辑走。** 从封面取主色铺成径向加线性的渐变，压一层暗罩保证歌词可读。横屏是滚筒式，越远的句子越小越暗。

**竖屏和横屏是两套渲染。** 竖屏是居中锚定的列表，横屏是滚筒，各自独立成模块，参数互不干扰。

## 技术

| | |
|---|---|
| 界面 | Kotlin · Jetpack Compose · Material 3 |
| 核心逻辑 | Rust（字级歌词模型、时间轴、TTML/LRC 解析、清单重写） |
| 播放 | Media3 / ExoPlayer |
| 玻璃效果 | Haze 2.0 |
| 网络 | OkHttp |
| 图片 | Coil 3 |
| 最低系统 | Android 8.0（API 26） |

模块结构：

```
app                     壳 / 导航 / DI
core-rust               FFI 出口
core-model              跨层模型
core-ui                 主题 / 字体 / 玻璃基元
core-glass              液态玻璃组件
core-network            传输 / 认证
core-playback           播放服务 / Media3 / DRM
data                    仓库层
feature-home / search / detail / library
feature-player-full     全屏播放
feature-lyrics-render   歌词渲染引擎
feature-lyrics-portrait 竖屏歌词页
feature-lyrics-floating 浮动歌词

crates/
  yuno-lyrics-model     字级粒度歌词模型
  yuno-lyrics-timeline  时间轴换算与渲染契约
  yuno-lyrics-ttml      TTML / LRC 解析
  yuno-drm-rewrite      清单重写与 DRM 头构造
```

| `core-ui/src/main/res/font/sf_pro.otf` | SF Pro | Apple Inc. |
